---
title: Select and Hand Tools
summary: The two tools that move you and your view around the canvas without drawing anything — the Select pointer and the Hand (Pan) tool.
aliases: cursor, pan tool, move tool
keywords: select, hand, pan, pointer, marquee, middle mouse, v, h
---

The **Select** tool (`kbd:V`) is the default pointer: it draws nothing and instead clicks, drag-selects, moves, resizes, and rotates whatever is already on the page. Clicking a shape gives it a blue outline with eight resize handles, a pivot point, and a rotate handle (a line gets one handle at each end instead). Drag across empty canvas to **marquee**-select every shape the box touches, even partially; `kbd:Shift+Click` adds or removes one shape from the selection.

The **Hand** tool (`kbd:H`) — also called Pan — likewise draws nothing; it drags the whole canvas around without touching any element. You rarely need to switch to it: holding the **middle mouse button** pans from inside any other tool, even mid-draw. Either way the cursor turns into an open hand, then a closed fist while you drag.

Both sit at the far left of the [toolbar](/docs/editor/canvas-basics#the-toolbar). See [Selecting, moving, resizing](/docs/editor/canvas-basics#selecting-moving-resizing) for the pointer and [Moving around the canvas](/docs/editor/canvas-basics#moving-around-the-canvas) for panning and zoom.
