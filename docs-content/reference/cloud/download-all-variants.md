**Download all variants (.zip)**, in the action column of any [project page](/docs/gallery/browsing-without-an-account#a-project-page), renders every [variant](/docs/reference/variants) the project defines — device sizes, color schemes, whatever the owner set up — as **one PDF each**, named after the variant, and hands you a single zip file. The rendering happens right in your browser (the button reads "Generating…" while it works), so give a large planner a moment. No account required.

A project with just one variant still works — the zip simply holds one PDF. For a planner published in A4, A5, and e-ink editions, this is the fastest possible path from "found it in the gallery" to "on my device": one click, one zip, every edition.

See [Download all variants](/docs/gallery/browsing-without-an-account#download-all-variants).
