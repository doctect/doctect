**Open in editor**, in the action column of any [project page](/docs/gallery/browsing-without-an-account#a-project-page), loads the project's published version into your editor as a new tab. No account, no confirmation, no waiting — from that moment it behaves like any project you built yourself. What lands is a **copy with no strings attached**: it lives in your browser like any local project and keeps **no link back to the original**, so nothing you do can touch the published project, and there's deliberately no "update from the original" or "send changes back."

That missing link is the whole contrast with a [fork](/docs/reference/fork): a fork is a signed-in cloud copy that *remembers* where it came from and can propose changes upstream, while Open in editor is the anonymous, one-way way to just take the design. Each row of a project's public [version history](/docs/gallery/browsing-without-an-account#time-travel-public-version-history) has its own Open in editor too, cloning that older snapshot the same no-strings way.
