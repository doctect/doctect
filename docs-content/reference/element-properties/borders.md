A shape's uniform border is the **Stroke** row in **Element Properties → Appearance**: a color swatch, a width field (`strokeWidth`), and a style dropdown — **Solid**, **Dashed**, **Dotted**, **Double**, or **None** (the `borderStyle` field). Style **None** or a width of 0 draws no border at all, regardless of the swatch color. For a border that differs edge to edge, click **Customize** to switch to [Per-Side Borders](/docs/reference/per-side-borders) instead.

Rounded corners are a separate control, **Radius** (`borderRadius`), sharing a row with [Opacity](/docs/reference/opacity) lower in the panel — a plain point value that rounds a rectangle's four corners. It has nothing to do with the Stroke style above it: a shape can have rounded corners with no border, or a square border with no rounding.

See [Strokes and borders](/docs/editor/elements-and-properties#strokes-and-borders) and, for Radius, [Rotation, opacity, stacking](/docs/editor/elements-and-properties#rotation-opacity-stacking).
