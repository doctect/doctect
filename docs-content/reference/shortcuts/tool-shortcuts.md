Each drawing tool has a single **bare key** — no `kbd:Ctrl` needed:

| Key | Tool |
| --- | --- |
| `kbd:V` | Select (pointer) |
| `kbd:H` | Hand / Pan |
| `kbd:T` | Text Box |
| `kbd:R` | Rectangle |
| `kbd:E` | Ellipse / Circle |
| `kbd:Y` | Triangle |
| `kbd:L` | Line |
| `kbd:G` | Data Grid |

Pressing a tool key does nothing while you are typing in a text field, so it never collides with normal typing. The **SVG Tools** menu is the one drawing control with no key of its own. See [The toolbar](/docs/editor/canvas-basics#the-toolbar), and the full [Shortcut reference](/docs/editor/canvas-basics#shortcut-reference).
