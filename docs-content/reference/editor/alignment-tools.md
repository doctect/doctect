Select two or more elements — [marquee](/docs/reference/select-and-hand-tools) across them, or `kbd:Shift`-click to add each in turn — and the toolbar grows a row of **alignment and distribution** buttons that isn't there for a single selection. There are eight operations: align left, center, and right; align top, middle, and bottom; and distribute horizontally or vertically to even out the gaps between shapes.

The row appears only at 2+ selected — with a single element there's nothing to align it against. Alignment and distribution each apply as a single undo step, so one `kbd:Ctrl+Z` puts the whole selection back where it was.

See [Selecting, moving, resizing](/docs/editor/canvas-basics#selecting-moving-resizing).
